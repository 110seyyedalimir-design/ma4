🔧 بستهٔ اصلاحی — نسخهٔ ۳

تغییر جدید (به درخواست خودت):
  بکاپ تلگرامی دیگر پیام قبلی را **ویرایش نمی‌کند**؛ هر بار **پیام تازه**
  می‌فرستد. برای جلوگیری از پر شدن گروه، حداکثر هر ۱۵ دقیقه یک پیام تازه
  (فقط وقتی داده‌ای عوض شده باشد).

  سه کلید تنظیم (در تب Variables ریپو — همه اختیاری‌اند):
    TGSTORE_MODE          = new (پیش‌فرض) | edit (رفتار قدیمی)
    TGSTORE_NEW_EVERY_MIN = 15   ← فاصلهٔ حداقلی دو پیام تازه (دقیقه)
    TGSTORE_DELETE_OLD    = 0    ← اگر 1 بگذاری، پیام قبلی را بعد از پیام تازه پاک می‌کند

چه کار کنم؟
۱) Actions → run در حال اجرا را Cancel کن.
۲) ریشهٔ ریپو → Add file → Upload files → این ۴ فایل را بکش (بازنویسی می‌شوند):
      tgstore.py   run_all.py   persist.py   restore_from_text.py
   → Commit changes
۳) داخل .github/workflows/ → bot-24x7.yml → مداد ✏️ → Ctrl+A → Delete →
   محتوای bot-24x7.yml این بسته را Paste → Commit changes
۴) Actions → bot-24x7 → Run workflow

در لاگ باید ببینی:
   [tgstore] 💾 بکاپ تازه در گروه فرستاده شد (پیام <شناسه>)
و در گروه، یک پیام **جدید** «🗂 داده‌های ربات» در بخش ذخیره ظاهر شود.
